# 🐍 CODSOFT Python Programming Internship

This repository contains the Python projects developed during my **Python Programming Internship at CODSOFT**. The projects focus on applying Python fundamentals to build simple, practical, and user-friendly applications.

##  Projects

### 1. To-Do List

A simple task management application for organizing daily activities.

**Features:**

* Add new tasks
* View tasks
* Mark tasks as completed
* Delete tasks

**Technologies:** Python, Tkinter



### 2. Calculator

A graphical calculator designed to perform common mathematical operations through an interactive interface.

**Operations:**

* Addition (+)
* Subtraction (-)
* Multiplication (×)
* Division (÷)
* Modulus (%)

**Technologies:** Python, Tkinter



### 3. Password Generator

A simple tool for generating random passwords based on the required length and character types.

**Features:**

* Set password length
* Generate random passwords
* Use letters and numbers
* Include special characters

**Technologies:** Python, Tkinter, Random, String
